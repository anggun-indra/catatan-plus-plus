Engineered for Performance

Everything you loved about Notepad++, made native on Mac.

⚡

Native Apple Silicon Speed

Built with pure C++17, Scintilla, Lexilla, and Cocoa. Starts up in less than 100 milliseconds and idles at under 25MB RAM with sub-millisecond typing latency.

🔄

Zero-Server In-Place Auto-Update

Silent background download via public GitHub Releases. When ready, click the 1-click restart button right in the bottom status bar for an instant atomic update with zero data loss.

📊

Offline Live Preview & Diagrams

Side-by-side and full-screen live rendering for Markdown, Mermaid diagrams, and PlantUML. Edit directly in the preview mode with automatic two-way synchronization.

🎨

90+ Languages & Notepad++ UDL

Complete syntax highlighting for 90+ programming languages powered by Lexilla. Import existing Notepad++ User Defined Language (XML) definitions seamlessly.

🛡️

5-Second Safe History & Autosave

Intelligent multi-line undo coalescing and temporary background snapshotting. Never lose code when pausing between sentences or hitting Enter.

🖥️

macOS Native Polish

Finder "Open With" integration, multi-tab session restoration, split-view scroll synchronization, clean Help menu, and native Dark Mode support.
