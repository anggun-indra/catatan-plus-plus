🛡️ First-time Launch Notice

Apple Gatekeeper / "Not Opened" Alert?

Catatan++ is free open-source software built from source and not signed with a paid Apple Developer certificate ($99/year). If macOS displays an alert upon first launch, simply run this one-time command in Terminal:

xattr -cr /Applications/Catatan++.app
Or open Finder → right-click Catatan++.app in /Applications → select Open → click Open.
System Requirements: macOS 11.0 (Big Sur), macOS 12 (Monterey), macOS 13 (Ventura), macOS 14 (Sonoma), or macOS 15 (Sequoia). Apple Silicon (M1/M2/M3/M4).
